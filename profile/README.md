## Support and contributions

Use the relevant project's issues for bugs and feature requests. Propose code
changes through fork-based pull requests; maintainers control merges and releases.
See each repository's contribution guide for local checks.

For suspected vulnerabilities, use **Security → Report a vulnerability** in the
affected repository. Do not disclose vulnerabilities in public issues.
